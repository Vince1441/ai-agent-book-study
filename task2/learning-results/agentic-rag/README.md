# Agentic RAG：本地法律语料检索

## 环境与任务

真实调用 Moonshot `kimi-k3`，检索后端为教材内置 BM25，语料来自 `chapter3/agentic-rag/laws`。此次索引 288 份文档、21372 个分块；无需外部 4242 检索服务。

问题：根据知识库中的刑法条文，故意杀人罪的法定刑是什么？请引用条文。

## 结果

Agentic 路径通过实际知识库工具调用找到了《刑法》第二百三十二条，并在回答中标记 `7-刑法/刑法_chunk_256`。单次检索路径没有取到目标条文，回答指出当前提供的上下文不足。

检索与回答是实际执行的结果；这是单题观察，未形成总体召回率、准确率或多跳推理评估。法律回答用于检索机制学习，未核查语料的现行有效性。

- `result.json`：问题、两条路径的完整回答和保留的会话信息。
- `run.log`：真实模型请求、知识库查询、命中文本及回答过程。

## 运行

从教材源码根目录执行 `python -u learning-results/task2/run_experiments.py agentic-rag`。依赖与密钥读取方式见[总说明](../README.md)。
